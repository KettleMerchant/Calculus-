Every circuit you'll ever analyze is asking the same question in disguise: how fast is this quantity changing right now? Current through a coil, voltage across a capacitor, a signal riding on a carrier wave — differential calculus is the toolkit that answers that question exactly, instead of by eye. This page walks through every rule you need to differentiate anything you'll meet this semester.

RULE 01

The Power Rule

The one you'll use more than any other. Bring the exponent down as a multiplier, then subtract one from it.

\dfrac{d}{dx}\left[x^{n}\right] = n\,x^{n-1}
Example \dfrac{d}{dx}\left[x^{5}\right] = 5x^{4}
Also works with negative and fractional powers \dfrac{d}{dx}\left[\dfrac{1}{x}\right] = \dfrac{d}{dx}\left[x^{-1}\right] = -x^{-2} = -\dfrac{1}{x^{2}}
Try it: differentiate f(x) = x⁷
f'(x) = 7x^{6}
RULE 02

Constant & Constant Multiple Rules

A flat, unchanging value has zero rate of change — its graph is a horizontal line, slope zero. A constant multiplying a function just rides along for the ride.

\dfrac{d}{dx}\left[c\right] = 0 \qquad\qquad \dfrac{d}{dx}\left[c\,f(x)\right] = c\,f'(x)
Example \dfrac{d}{dx}\left[7x^{3}\right] = 7 \cdot 3x^{2} = 21x^{2}
Try it: differentiate f(x) = 12 and g(x) = −4x⁶
f'(x) = 0 \qquad g'(x) = -24x^{5}
RULE 03

Sum & Difference Rule

Differentiate a sum by differentiating each term separately, then adding the results back together. No cross-terms, no surprises.

\dfrac{d}{dx}\left[f(x) \pm g(x)\right] = f'(x) \pm g'(x)
Example \dfrac{d}{dx}\left[x^{4} - 3x^{2} + 5x\right] = 4x^{3} - 6x + 5
Try it: differentiate f(x) = 2x³ + x² − 9
f'(x) = 6x^{2} + 2x
RULE 04

Product Rule

This is where people get burned — you cannot just multiply the two derivatives. Instead: derivative of the first times the second, plus the first times derivative of the second. "First-D-Second plus Second-D-First."

\dfrac{d}{dx}\left[f(x)g(x)\right] = f'(x)g(x) + f(x)g'(x)
Example — f(x) = x², g(x) = sin(x) \dfrac{d}{dx}\left[x^{2}\sin x\right] = 2x\sin x + x^{2}\cos x
Try it: differentiate h(x) = x³ eˣ
h'(x) = 3x^{2}e^{x} + x^{3}e^{x} = x^{2}e^{x}(3 + x)
RULE 05

Quotient Rule

For a ratio of two functions. Mnemonic: "Low-D-High minus High-D-Low, over the square of what's below."

\dfrac{d}{dx}\left[\dfrac{f(x)}{g(x)}\right] = \dfrac{f'(x)g(x) - f(x)g'(x)}{\left[g(x)\right]^{2}}
Example — f(x) = x, g(x) = x + 1 \dfrac{d}{dx}\left[\dfrac{x}{x+1}\right] = \dfrac{(1)(x+1) - (x)(1)}{(x+1)^{2}} = \dfrac{1}{(x+1)^{2}}
Try it: differentiate f(x) = sin(x) / x²
f'(x) = \dfrac{x^{2}\cos x - 2x\sin x}{x^{4}} = \dfrac{x\cos x - 2\sin x}{x^{3}}
RULE 06

Chain Rule

For a function nested inside another — the single most important rule for real engineering signals (think \sin(\omega t)). Differentiate the outside, leave the inside alone, then multiply by the derivative of the inside.

\dfrac{d}{dx}\Big[f\big(g(x)\big)\Big] = f'\big(g(x)\big)\cdot g'(x)
Example \dfrac{d}{dx}\left[\sin(3x^{2})\right] = \cos(3x^{2}) \cdot 6x = 6x\cos(3x^{2})
The signal you'll see constantly \dfrac{d}{dt}\left[\sin(\omega t)\right] = \omega \cos(\omega t)
Try it: differentiate f(x) = (4x + 1)⁵
f'(x) = 5(4x+1)^{4}\cdot 4 = 20(4x+1)^{4}
RULE 07

Trigonometric Derivatives

Six to memorize cold — they show up in every AC signal, phasor, and oscillation you'll model.

\dfrac{d}{dx}[\sin x] = \cos x \qquad \dfrac{d}{dx}[\cos x] = -\sin x \qquad \dfrac{d}{dx}[\tan x] = \sec^{2}x
\dfrac{d}{dx}[\csc x] = -\csc x \cot x \qquad \dfrac{d}{dx}[\sec x] = \sec x \tan x \qquad \dfrac{d}{dx}[\cot x] = -\csc^{2}x

Notice the pattern: co-functions (cosine, cosecant, cotangent) always pick up a minus sign.

Try it: differentiate f(x) = x·cos(x)
f'(x) = \cos x - x\sin x

(Product rule + trig derivative, working together.)

RULE 08

Exponential & Logarithmic Derivatives

e^{x} is the only function that is its own derivative — the reason it governs every natural growth and decay process, including RC-circuit charging curves.

\dfrac{d}{dx}\left[e^{x}\right] = e^{x} \qquad \dfrac{d}{dx}\left[a^{x}\right] = a^{x}\ln a \qquad \dfrac{d}{dx}\left[\ln x\right] = \dfrac{1}{x}
Example — chain rule with e \dfrac{d}{dx}\left[e^{-t/RC}\right] = -\dfrac{1}{RC}\,e^{-t/RC}
Try it: differentiate f(x) = ln(5x² + 1)
f'(x) = \dfrac{10x}{5x^{2}+1}
